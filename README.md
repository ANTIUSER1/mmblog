# Бэкэнд для блога : Возможности

* Созание поста : POST: /api/posts
  Передать в теле
  {
  "title": "Название поста 3",
  "content": "Текст поста в формате Markdown...",
  "tags": ["tag_1", "tag_2"]
  }
* Получение поста (на странице поста) — метод POST: /api/posts/1
* Редактирование поста (на странице поста) — метод PUT: /api/posts/3
* Удаление поста (на странице поста) — метод DELETE: /api/posts/1

* Добавление комментария к посту — метод POST: /api/posts/1/comments
  Передать в теле
  {
  "content": "Текст комментария..."
  }
* Получение комментария поста — метод GET: /api/posts/1/comments/2
  1 -- номер поста, 2 -- номер коммента
* Редактирование комментария к посту — метод PUT: /api/posts/1/comments
  1 -- номер поста, 2 -- номер коммента
  Передать в теле
  {
  "content": "Текст комментария... ИСПРАВЛЕНИЕ ........."
  }
